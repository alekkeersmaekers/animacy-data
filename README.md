Training and test data used in _Keersmaekers (forthcoming), Animacy annotation for Ancient Greek: comparing two transformer-based approaches_.

# Data format
_dataset_anim_tabular_ and _dataset_animacy_papyri_ are the training data, while _random_sample_glaux_translations_annotated_ is the test data. _dataset_anim_tabular_ and _random_sample_glaux_translations_annotated_ only include GLAUx-IDs (in the ID column) and not the sentence: the respective sentence can be retrieved from the GLAUx corpus at https://github.com/alekkeersmaekers/glaux. _dataset_animacy_papyri_ contains TM-wordids (from https://github.com/alekkeersmaekers/duke-nlp), the word form and the class for the full sentences, which are separated by newline characters.
